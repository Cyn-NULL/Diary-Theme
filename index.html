02 · INSTALL

적용 방법

파일 두 개를 Risu의 Custom HTML · Custom CSS 칸에 붙여 넣으면 끝납니다.

  1. 파일 받기

    다운로드 링크에서 theme.html과 theme.css를 받습니다.

  2. Custom HTML 선택

    RisuAI 표시 설정에서 채팅 표시 방식을 Custom HTML로 바꿉니다.

  3. 붙여 넣기

    HTML 칸에 theme.html, CSS 칸에 theme.css 내용을 그대로 붙여 넣습니다. CSS는 <style>로 감싸지 않습니다.

03 · CUSTOM

조절할 수 있는 값

theme.css 위쪽 .y2kd 안의 값만 바꾸면 됩니다.

변수기본값설명
--y2kd-font-size15px본문 글자 크기. 앱의 글자 크기 설정과 따로 움직입니다.
--y2kd-line-height1.8본문 줄 간격
--y2kd-text-max-height520px본문 스크롤 높이. none이면 스크롤 없이 늘어납니다.
--y2kd-width1100px카드 전체 폭
--y2kd-avatar-filternone프로필 사진 효과. grayscale(1)이면 흑백
--y2kd-avatar-positioncenter 25%프로필 사진에서 보이는 위치
--y2kd-quote-band#cfe6ff대사 형광펜 색
--y2kd-thought-bg회색 그라데이션생각 메모지 바탕
